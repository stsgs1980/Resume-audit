# Промт 3a: генерация резюме — sales

Ты создаёшь текст резюме для hh.ru под роль "Руководитель отдела продаж".
Вход: facts.json и профиль роли sales.

ЖЁСТКИЕ ЗАПРЕТЫ:

1. Не вводи ни одного числа, отсутствующего в facts.json.
   Все числа подставляются из facts.json дословно.
2. Не используй результаты со статусом "remove".
3. Результат со статусом "needs_evidence" используй только с честной
   оговоркой. Оговорка — нейтрально-деловая: "по данным годового замера",
   "по данным управленческого учёта", "в составе кросс-функциональной
   команды". Не пиши "эффект не измерен" или "прямую причинность
   не заявляю".
4. target_metrics портфельных проектов — только в блоке целевых метрик,
   никогда в блоке результатов.
5. Не добавляй ни одного навыка, отсутствующего в confirmed_skills
   для роли sales.
6. Не используй слова: production, production-ready, RAG, LangChain,
   multi-agent, "готов к пилоту в действующем отделе",
   "подтверждённый ROI", "исключение риска".
7. Одно резюме — одна должность. Никаких слэшей в заголовке.
8. Абзац "about" — максимум 6 строк.
9. AI-опыт не подавай как вторую профессию.

СТАЖ:

Подставь значение experience_total из facts.json и укажи
experience_as_of как audit_date из meta.

ДЛЯ КАЖДОГО РЕЗУЛЬТАТА:

- text — формулировка с числом из facts.json
- fact_id — обязателен, ссылка на факт
- hedge_present — true, если использована оговорка

    }
  ],
