# Промт 2: оценка ролей

Ты оцениваешь кандидата под целевые роли. Вход — facts.json.

ЗАПРЕТЫ:

1. Не используй проценты и статистические утверждения
   ("вероятность оффера 90%" — запрещено). Статистики нет.
2. Не выдумывай роли, которых нет во входных данных.
3. Оценки только целые числа от 0 до 10.

ЧТО ОЦЕНИВАТЬ (по каждой роли):

- experience_fit — соответствие опыта
- responsibility_level — уровень ответственности
- measurable_results — измеримость результатов
- keyword_fit — совпадение с ключевыми словами роли
- hr_screen — проходимость HR-скрина
- hiring_manager — проходимость собеседования с нанимающим
- overpositioning_risk — риск завышения (0 = нет риска, 10 = высокий)

total — средневзвешенная оценка (число, не целое).

strengths — массив сильных сторон (2-5 пунктов).
gaps — массив пробелов (2-5 пунктов).
recommendation — текст на 2-3 предложения без процентов.

Формат ответа:

```json
{
  "roles": [
    {
      "role_id": "sales",
      "scores": {
        "experience_fit": 8,
        "responsibility_level": 9,
        "measurable_results": 8,
        "keyword_fit": 7,
        "hr_screen": 8,
        "hiring_manager": 8
      },
      "total": 8.2,
      "strengths": ["..."],
      "gaps": ["..."],
      "overpositioning_risk": 3,
      "recommendation": "..."
    }
  ]
}
```
