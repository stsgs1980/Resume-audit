# SPEC-dates: конвенция дат и стаж

Часть спецификации Resume Audit.
См. также: [SPEC.md](SPEC.md).

## 1. Включительный подсчёт

Фундамент всего расчёта стажа. Ошибка здесь ломает все производные цифры.

```text
function monthsInclusive(start: YearMonth, end: YearMonth): number {
  return (end.year - start.year) * 12 + (end.month - start.month) + 1;
}
```

Это не произвольный выбор: включительный подсчёт воспроизводит
все пять известных длительностей, которые показывает hh.ru.

| Период             | Исключительно | Включительно | hh.ru      |
| ------------------ | ------------: | -----------: | ---------- |
| 2003-10 -> 2005-07 |            21 |           22 | 1 г 10 мес |
| 2005-07 -> 2018-12 |           161 |          162 | 13 л 6 мес |
| 2019-11 -> 2023-11 |            48 |           49 | 4 г 1 мес  |
| 2024-04 -> 2024-10 |             6 |            7 | 7 мес      |
| 2024-12 -> 2025-09 |             9 |           10 | 10 мес     |

При исключительном подсчёте приложение занизит стаж на месяц в каждом
месте работы и перестанет совпадать с hh.ru.

## 2. Значение present

`present` — последний завершённый месяц относительно `audit_date`
из `meta`.

Пример: аудит 9 октября 2026, значит `present` = сентябрь 2026.
Период 2025-10 -> `present` включительно = 12 месяцев = 1 год 0 мес.

## 3. Слияние интервалов

Включительный интервал `[s, e]` хранится как полуоткрытый `[s, e+1)`.
Слияние — стандартное объединение полуоткрытых интервалов: если
`next.s <= current.e`, расширяем `current.e = max(current.e, next.e)`.

Это критично. Два последовательных места работы, где конец первого
и начало второго — один и тот же месяц, дают наивную сумму на месяц
больше истины.

Пример: Компания А заканчивается в 2005-07, Компания Б начинается
в 2005-07. Стык посчитан дважды.

## 4. Двойной расчёт стажа

Стаж считается двумя способами. Оба показываются пользователю.

```text
// Наивная сумма — воспроизводит конвенцию hh.ru
const naiveMonths = sum(jobs.map((j) => monthsInclusive(j.start, j.endResolved)));

// Объединение интервалов — истина, без двойного счёта
const distinctMonths = unionLength(jobs.map(toHalfOpen));
```

На тестовом наборе:

- наивная сумма: 262 месяца = 21 год 10 месяцев;
- объединение: 261 месяц = 21 год 9 месяцев;
- разница в один месяц — стык 2005-07, посчитанный дважды.

## 5. Правило отображения

Обе цифры показываются рядом с подписью:

- «21 год 10 месяцев — расчёт по конвенции hh.ru»;
- «21 год 9 месяцев — без двойного учёта стыка 2005-07».

В сгенерированное резюме попадает наивная цифра, чтобы не расходиться
с тем, что видит кандидат на hh.ru.

Расхождение фиксируется в `audit.json` как предупреждение.

## 6. Смежность и параллельность

- Смежность (`prev.end == next.start`) — нормальная последовательность,
  не параллельность.
- Параллельные роли с одинаковым `overlap_group` объединяются
  в один интервал.
- Роли с разными `overlap_group` и пересекающимися периодами — признак
  необъяснённого параллельного опыта, выдавать предупреждение.

## 7. Разрывы

Разрыв строго больше 3 месяцев между концом одного места и началом
следующего — предупреждение с точными датами.

Ровно 3 месяца — не разрыв. Порог строгий, граница не флагуется.

## 8. Извлечение дат из цитат

`extractDateRange` возвращает `start`, `end`, `year`, `confidence`, `isCurrent`.

Полная дата месяца (`YYYY-MM`, `MM.YYYY`, «октябрь 2003») — единственный
источник `start`/`end`. Голый год — не дата: месяц 01 не подставляется,
год возвращается в поле `year`.

| confidence | Когда                                        | start/end                 |
| ---------- | -------------------------------------------- | ------------------------- |
| high       | только даты месяца (ISO, MM.YYYY, месяц+год) | из дат месяца             |
| medium     | смешанная точность: дата месяца + голый год  | end не выдумывается: null |
| low        | только голые годы                            | null                      |
| null       | дат нет                                      | null                      |

«Привлёк 2000 клиентов за год» даёт `start: null, end: null,
year: "2000", confidence: "low"` — метрика не превращается в дату 2000-01.

В этапе 4 цитаты с `confidence: "low"` не создают работу и не участвуют
в её датах; если других цитат у компании нет — warning «недостаточно
данных для дат».

## 9. Стаж как функция даты

Значение меняется каждый месяц. На 9 сентября 2026 наивная сумма даёт 262,
на 9 октября 2026 даст 263.

Поэтому стаж не хранится текстом — подставляется при генерации.
В UI показывается с меткой «действительно на <audit_date>», чтобы
пользователь понимал, когда текст устареет.
