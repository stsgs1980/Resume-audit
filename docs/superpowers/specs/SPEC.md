# Resume Audit — спецификация

Версия: 1.0
Дата: 2026-10-14
Статус: ACTIVE

## Назначение

Resume Audit — локальное веб-приложение для строгого аудита резюме
под поиск работы на hh.ru.

Приложение решает главную проблему LLM-генерации резюме — галлюцинации —
архитектурно, а не промптом «не выдумывай». Источник правды (`facts.json`)
отделён от генерации. Все числа проверяются кодом. Экспорт заблокирован
до полной согласованности.

Работает на `127.0.0.1`, использует локальный opencode server как
LLM-провайдер. Данные не покидают машину, кроме вызовов модели.

## Целевые роли

Приложение готовит три версии резюме под одну из трёх ролей.

| Роль     | Описание                      |
| -------- | ----------------------------- |
| sales    | Руководитель отдела продаж    |
| salesops | Руководитель Sales Operations |
| aipo     | AI Product Owner (продажи)    |

Каждая версия — отдельный документ со своим системным промтом,
per-role allowlist и набором ключевых слов.

## Принципы

1. Источник правды — `facts.json`. Только подтверждённые факты.
2. Производные — вычисляются, не хранятся.
3. LLM — недоверенный компонент. Формулирует, но не выдумывает.
4. Числа проверяются кодом. Слой 1 не обходится слоем 2.
5. Экспорт — fail-closed.
6. Человек в цикле обязателен. Без evidence факт не подтверждён.
7. Трассируемость в обе стороны. От выхода к цитате, от цитаты к факту.

## Что делает и чего не делает

### Что делает

- Читает `*.md`, `*.txt`, `*.docx`, `*.pdf`, `*.html`.
- Классифицирует файлы: `hh_export`, `resume_draft`, `vacancy`,
  `flagged_synthetic`, `ai_inflated`, `technical_audit`, `unknown`.
- Извлекает факты с обязательной цитатой.
- Строит канон фактов через подтверждение человеком.
- Ищет противоречия между версиями.
- Генерирует три версии резюме.
- Верифицирует результат в два слоя.
- Экспортирует `.md`, `.txt`, JSON, копирует блоками для hh.ru.

### Чего не делает

- Не обращается к hh.ru и не скрейпит сайт.
- Не знает алгоритмов ранжирования hh.ru.
- Не выдумывает факты.
- Не проверяет факты через работодателей.
- Не публикует резюме без верификации.
- Не делает вероятностных утверждений о найме.
