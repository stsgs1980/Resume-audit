# BUILD.md: план сборки Resume Audit

План по этапам. Каждый этап — отдельный коммит.
См. также: [SPEC.md](../specs/SPEC.md).

## Принципы

1. Сначала ядро, потом LLM. Пока тесты ядра не зелёные, LLM-этапы
   не запускаются.
2. Каждый шаг заканчивается зелёными линтерами и тестами.
3. Один коммит — одно логическое изменение.
4. Conventional Commits: `type(scope): description`.
