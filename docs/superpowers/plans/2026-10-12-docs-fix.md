# Docs consistency fix Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development
> (recommended) or superpowers:executing-plans to implement this plan task-by-task.
> Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Убрать противоречия в docs чтобы агент создавал проект из шаблона без двусмысленности.

**Architecture:** Точечные правки `README.md`, `README.template.md`, `docs/*.md` и AI Rules.
Единый порядок шагов, Verify выровнен с CI, явные решения про `react`, `tests/`, CHANGELOG.

**Tech Stack:** Markdown, markdownlint, Prettier, Conventional Commits.

**Spec:** Аудит docs от 2026-10-12: `README.md`, `README.template.md`, `docs/getting-started.md`,
`docs/webstorm.md`, `docs/testing.md`, `docs/markdown.md`, `.aiassistant/rules/AI Rules.md`,
`package.json`, `.github/workflows/ci.yml`, `.husky/*`, `vitest.config.ts`, `.gitignore`.

## Global Constraints

- Always respond in Russian.
- Max line length 120 chars, aligned tables, `npm run lint:md` green.
- Fenced code blocks must specify language, JSX examples only in `tsx`.
- ASCII only: `->` not arrow, `...` not ellipsis, tags `[OK]`, `[FAIL]`, `[TODO]`.
- Max file length 250 lines, strict TS where code touched.
- Commits in Conventional Commits format, do not commit directly to main without verification.

## Review Focus

- Новый агент читает только Quick Start и останавливается после `npm install` -> ждет явную
  ссылку на обязательные шаги после fork, тест: checklist присутствует и линкуется.
- Проект без React удаляет `react` и ломает `eslint.config.js` -> ждет явную инструкцию что править.
- Агент на feature-ветке ждет генерации CHANGELOG -> ждет пометку "только main".
- Агент удаляет `tests/` как пример -> ждет явное "не удалять, это проверка тулчейна".
- Пустые `docs/superpowers/plans/, specs/` пропадают после fork -> ждет объяснение или `.gitkeep`.
